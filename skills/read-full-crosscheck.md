# 读全校验：三层 · 四判据 · 可复算判分

## 何时用

- 要验证自己（或另一个模型）对一份长文档/题面/指令的复述是否忠实。
- 两个模型经人肉中继对话，需要互相判分、留档、算总账。
- 收到长指令后要出「我理解的是……」回执，且必须可被逐条核对。
- 任何「看起来都读对了、但结论还是错了」的事故复盘。

## 第一原则：读全分三层

1. **字符层**：字有没有收到、有没有变形（校验串负责）。
2. **命题层**：每条规定、限定、例外、否定有没有保留。
3. **关系层**：命题之间的关系重建对不对——谁做的、哪一层说的、是必要还是充分、是执行还是许可、是并存还是排斥。

> 经验：字符层和命题层很容易全对，事故几乎都在关系层。判读时把注意力压在第三层。

## 四项判据

| 判据 | 看什么 | 失败典型 |
|---|---|---|
| 完整性 | 关键命题、限定条件、例外、否定是否全在 | 漏「提前做的不算数」；漏「改标点也算复用」 |
| 准确性 | 数量、指代、逻辑关系、认识状态是否被改 | 主体换了人；条件类型换了；开闭区间变了 |
| 边界识别 | 区分事实／引述／推测／操作要求／沉默 | 把引述当立场；把未记载当没发生 |
| 逐字校验 | 校验串一字不差 | 括号、生僻字被吃 → 先怀疑通道 |

全部满足才通过；单条错误按性质记录，不把误读等同于编造。

## 校验串设计

- 形式：`【CHK-<序号><生僻字>-<干支>-<时辰>】`，例：`【CHK-9银潮-乙亥-昏】`
- 要点：全角括号 + 生僻字 + 无意义组合，防自动纠错、防猜。
- 用法：接收方第一行逐字回显。失配时按归因表处理，不直接判模型错。
- 诚实的边界：只到「两端同源、未失配」，**不能**说「通道经独立复核」——除非真做过发送前核对。

## 常见偏移清单（按出错概率排序）

1. **主体错置**：把 A 做过的事记成 B 做的；跨轮次把「上一轮的接收方」和「本轮的接收方」混为一谈。
2. **证据层级上移**：把「记录里写着 X」升级成「X 发生过」；转述链只该确认「记录存在」，不该确认每一级转述发生。
3. **权限/分工外延**：题面给的是分工，写成「权限清单」；「没有行使审批权」被读成「有审批权」。
4. **条件类型互换**：「只要…就…」是充分，被读成必要；「只有…才…」反过来。
5. **许可 ≠ 行动**：满足必要条件 ≠ 已获许可；有资格 ≠ 动手；没资格 ≠ 没动手。
6. **否定 vs 未表态 vs 沉默**：未否决、未批准、未答复是三种不同状态；「未记载」不等于「没发生」。
7. **未否认 ≠ 确认**：无人否认某事 ≠ 该事成立，也 ≠ 有人确认过。
8. **先后 ≠ 因果**：「在…之后」只给时序。
9. **集合关系被补全**：给了 7/4/3/2 四个数，不能擅自决定哪个集合包含哪个。
10. **转述塌层**：三层引述被压成一层，中间说话人消失。
11. **区间开闭**：「严格长于 48 小时」= 开下界；「不超过五天」= 闭上界。端点易错。
12. **程序 ≠ 实体**：申请被退回（材料不齐）≠ 许可被拒；补交材料 ≠ 获批。

## 判分流程（可复算）

1. 校验串比对 → 记录逐字栏。
2. 逐项对照，列出：命中 / 遗漏 / 篡改 / 外延。每处都指到原句。
3. 分栏记：语义栏（命中/遗漏/篡改）、边界栏、逐字栏。
4. 计分口径（若需总分）：每题四项各 1 分；同一判据内多处轻伤封顶扣 0.5；判未通过项记 0；各取已答题平均（题量不等时必须取平均，不能取总数）。
5. 定性用词要稳：误读／自曝的误读／编造／遗漏／认识层级变化——分开写，禁止把误读写成编造。
6. 尺度一致性：判过之后再看前几轮，若两把尺子不齐，主动摆出敏感性（回溯会怎样），不追溯但要留档。

## 接收方自查（出回执前过一遍）

- [ ] 我复述的每个动作，主语是否确实是原文的主语？
- [ ] 我有没有把「记录/引述/声称」写成「事实」？
- [ ] 我有没有把「分工」写成「权限」，把「必要」写成「充分」？
- [ ] 我有没有替原文补上它没写的东西（哪怕只是小半步）？
- [ ] 校准句：**读完之后不要替对方把话补完。** 缺的就说缺。

## 出题方自查（若要做压力题）

- 只给命题，不给提示句。凡出现「题面没有穷举……」「题面没有记载原因」这类句子，等于把答案半写在题面上——坑挖浅了。
- 埋点在关系层，不在词汇层。
- 作废必须换全新题，不得改词改标点复用（防二次接触污染）。

## 中继归因表（人工搬运时用）

| 发现的问题 | 判定 |
|---|---|
| 发送前或搬运中字符损坏 | 中继损耗，作废换题 |
| 确认送达正确，接收方复现错误 | 逐字失败 |
| 无法定位损坏发生在哪一环 | 归因未定，不计成绩，换题 |
| 两端完全一致 | 逐字通过（但仅「两端同源」） |
